# 1. RSA 구조

RSA는 공개 키 암호 방식 중 하나이다.

대칭 키 암호는 암호화와 복호화에 같은 키를 사용하지만, RSA는 서로 다른 두 개의 키를 사용한다.

```
공개키 : 다른 사람에게 공개할 수 있는 키
개인키 : 나만 가지고 있어야 하는 키
```

RSA에서는 보통 공개키로 암호화하고, 개인키로 복호화한다.

```
암호화 : 평문^e mod n = 암호문
복호화 : 암호문^d mod n = 평문
```

여기서 공개키는 `(n, e)`이고 개인키는 `(n, d)`이다.

공개키는 남에게 알려져도 되지만, 개인키는 절대 노출되면 안 된다.

---

# 2. RSA가 소수를 사용하는 이유

RSA는 처음에 두 개의 소수를 선택한다.

```
p = 소수
q = 소수
```

그리고 두 소수를 곱해서 `n`을 만든다.

```
n = p × q
```

예를 들어 다음과 같이 작은 수를 사용할 수 있다.

```
p = 61
q = 53
n = 61 × 53 = 3233
```

작은 수에서는 `3233 = 61 × 53`이라는 것을 쉽게 찾을 수 있다.

하지만 실제 RSA에서는 훨씬 큰 소수를 사용한다.

두 큰 소수를 곱해서 `n`을 만드는 것은 쉽지만, `n`만 보고 다시 `p`와 `q`를 찾는 것은 어렵다.

RSA는 이 차이를 이용한다.

```
곱하기는 쉽다.
다시 쪼개기는 어렵다.
```

즉, RSA의 안전성은 큰 수의 소인수분해가 어렵다는 점에서 나온다.

# 3. 모듈러 연산

모듈러 연산은 나머지를 구하는 연산이다.

```
17 mod 5 = 2
```

17을 5로 나누면 나머지가 2이기 때문이다.

RSA에서는 거듭제곱 계산이 많이 나온다.

```
m^e
c^d
```

그런데 이런 값은 숫자가 너무 커진다.

그래서 RSA는 계산 결과를 항상 `n`으로 나눈 나머지로 줄인다.

```
m^e mod n
c^d mod n
```

이렇게 하면 숫자가 커지더라도 정해진 범위 안에서 계산할 수 있다.

# 4. RSA 키 생성 흐름

RSA 키 생성은 다음 순서로 진행된다.

```
1. 두 소수 p, q를 고른다.
2. n = p × q 를 계산한다.
3. φ(n) = (p - 1)(q - 1)를 계산한다.
4. 공개 지수 e를 정한다.
5. 개인 지수 d를 구한다.
```

예시는 다음과 같다.

```
p = 61
q = 53

n = p × q
n = 3233

φ(n) = (p - 1)(q - 1)
φ(n) = 60 × 52
φ(n) = 3120
```

`φ(n)`은 오일러 피 함수이다.

여기서는 `n`보다 작으면서 `n`과 서로소인 수의 개수라고 이해하면 된다.

RSA에서는 `e`와 `d`가 다음 조건을 만족해야 한다.

```
e × d ≡ 1 mod φ(n)
```

예를 들어 다음 값이 가능하다.

```
e = 17
d = 2753
```

확인하면 다음과 같다.

```
17 × 2753 mod 3120 = 1
```

이 조건 때문에 공개키로 암호화한 값을 개인키로 다시 복호화할 수 있다.

---

# 5. 암호화와 복호화

평문을 숫자 `123`이라고 해 보자.

```
m = 123
```

공개키 `(n, e)`를 사용해 암호화한다.

```
c = m^e mod n
c = 123^17 mod 3233
c = 855
```

암호문은 `855`가 된다.

이제 개인키 `(n, d)`를 사용해 복호화한다.

```
m = c^d mod n
m = 855^2753 mod 3233
m = 123
```

결과가 다시 원래 평문 `123`으로 돌아온다.

---

# 6. 왜 다시 원래 값으로 돌아오는가?

RSA의 핵심은 `e`와 `d`가 서로 반대 역할을 하도록 만들어졌다는 점이다.

```
e × d ≡ 1 mod φ(n)
```

즉, `e`는 잠그는 방향이고 `d`는 푸는 방향이다.

```
평문
  ↓ 공개키 e
암호문
  ↓ 개인키 d
평문
```

이 구조가 가능하려면 `φ(n)`을 알아야 한다.

그런데 `φ(n)`을 계산하려면 `p`와 `q`를 알아야 한다.

공격자는 공개키 `(n, e)`를 볼 수 있지만, `p`와 `q`를 모르면 `φ(n)`을 계산하기 어렵다.

그래서 개인키 `d`도 구하기 어렵다.

```

3. e와 φ(n)이 서로소인지 확인한다.
4. 조건을 만족하는 d를 찾는다.
